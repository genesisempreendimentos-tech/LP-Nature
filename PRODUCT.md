# Nature Residencial — Product

Landing page de conversão do Nature Residencial (Gênesis Empreendimentos).  
Local: Alto, Teresópolis — RJ.

## Design read

Landing premium editorial/arquitetônica para compradores de alto padrão — linguagem minimalist architectural (guidelines do projeto), VARIANCE 6 / MOTION 5 / DENSITY 3.

## Argumento central

**Nature. O essencial em um novo padrão.**

## Stack

React 19 · Vite · Tailwind CSS v4 · GSAP + @gsap/react · Playfair Display + Inter

## Skills usadas neste ciclo

- `design-taste-frontend` / `frontend-design` — direção editorial, anti-slop, hierarquia
- `impeccable` + guidelines — tokens, whitespace, tipografia
- `emil-design-eng` / animate — motion com ease-out, active states, transitions específicas
- `ui-ux-pro-max` — ritmo de seções e composição
